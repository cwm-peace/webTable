# WebTable 本机填写工具

Vue 3 静态网页。填写内容和图片在使用者的浏览器中处理，以 IndexedDB 保存草稿，在本机生成 PDF。网站不提供账号、后台管理、上传或接收填写结果的接口。

## 使用

1. 确认已满18周岁。每份草稿确认一次，刷新同一份草稿不重复询问。
2. 填写32项基础资料、125项自评级别及备注，选择四类共16张不同图片。文字无对应内容时可填“无”或“不适用”。
3. 生成PDF，点击下载或打开后保存。PDF包含全部正文、图片和16个图片附件。
4. 检查文件可打开，勾选已保存并再次确认，清除应用内草稿、图片和生成文件。下载目录、相册及设备备份仍由使用者管理。

草稿约1秒自动保存，刷新后可继续。另一个标签页正在编辑时，本页只读；意外关闭后的租约最长约9秒到期。保存冲突保留本页编辑，重新读取前请自行确认。存储不可用时，可以明确选择临时填写；刷新或关闭会丢失临时内容。清理时如果存储仍不可访问，页面会明确提示磁盘清理未验证，不会宣称全部清除。

## 本机开发与构建

使用 Node.js 22.13以上版本及 npm。

```bash
npm ci
npm run dev         # http://127.0.0.1:5174
npm run build       # 输出 dist/
npm run serve:static # 生产构建预览，默认127.0.0.1:5174
```

开发和静态服务使用相同端口，请分别启动。端口可用 `PORT=5180 npm run serve:static` 修改。公开部署只发布 `dist/`，须使用HTTPS；不要把源码、测试、恢复目录和整个项目目录作为静态根目录。无需Java、MySQL或Redis。部署说明见 [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)。

```bash
npm test
npx playwright install chromium firefox webkit
npm run test:e2e
npm run verify:rounds # 固定构建，连续11轮；约需十几分钟或更久
```

## 图片与PDF

支持JPEG、PNG、WebP，并按浏览器内置解码器支持GIF、BMP、AVIF、TIFF、SVG、HEIC／HEIF（HEIC／HEIF取决于浏览器，Safari可解、Chrome不可解并明确提示转换）。格式按真实文件内容检查，改扩展名不能绕过判重。单张输入上限64 MiB；超过2500万像素或最长边8192时自动等比缩小，超过200兆像素或最长边32768才明确拒绝。动图（GIF、APNG、动画WebP）自动取第一帧。原图同时满足不超过2 MiB、1300万像素、最长边4096且为静态JPEG/PNG/WebP时保留原字节。其余在本机生成压缩JPEG附件并标记，附件不超过2 MiB。预览图独立生成，不替换符合条件的原件。

图片按原始与最终文件SHA-256判重，改文件名无法绕过；不同编码但视觉相似的图片不做识别。原字节可能包含EXIF位置等信息；动图和矢量图不会被保留为原件。PDF为报告式版面（标题区、章节色带、两列资料网格、自评表格、单页照片配细边框，页眉页脚与页码），只用黑白灰三级灰阶，中文标题与正文同属一个内置字重，不引入彩色或额外字体。PDF嵌入同源中文字体；字体没有字形的字符（例如 emoji）会在生成时用 □ 代替，并在页面提示和 PDF 正文中列出被替代的码位，不静默丢字、也不阻断导出，草稿原文保持不变。系统PDF预览器可能不显示附件列表，提取原件需使用支持附件的阅读器。

三种外观（极简、科技、扁平）与浅色、深色、跟随系统独立选择。外观偏好存于localStorage，填写内容只在IndexedDB或明确选择的页面内存中。

## 架构

- `src/data/`：固定32字段、125题元数据。
- `src/lib/storage.js`、`autosave.js`：事务、写入租约、版本、清除代次与串行自动保存。
- `src/lib/images.js`、`imageHeader.js`、`src/workers/image.worker.js`：文件校验、摘要和图片处理。
- `src/lib/pdf.js`、`pdfCore.js`、`pdfLayout.js`、`src/workers/pdf.worker.js`：按需加载、正文与附件、取消和本机回退。
- `src/stores/`、`src/components/`：表单与外观状态、响应式填写界面。
- `scripts/`、`tests/`、`e2e/`：静态预览、带宽测量、测试和回归。

后端及管理员页面已从活动项目移除，原数据库没有删除。重构前代码和未提交改动保存在项目外的本机恢复目录；恢复目录不属于部署包。
