# 纯前端工具的法律审查范围与责任边界

2026-10-14修订。本次纠正此前报告中的归责范围：使用者浏览器在本机处理文件，不等于工具作者取得或处理这些文件；使用者自行展示、转发或另行部署，也不能直接写成作者的行为或整改义务。本记录对照工程事实与相关法条，不作司法认定或零风险保证。

## 审查所依据的事实

- 作者提供公开、免费、无商业用途的工具，不接收填写内容、图片或PDF，看不到这些内容，也不要求使用者交付结果。
- 现有实现没有上传、后台管理、远程查看、接收填写结果或公开分享用户内容的接口。录入、图片处理、草稿保存及PDF生成由使用者的浏览器在本机完成。
- 每份草稿开始时要求使用者声明已满18周岁。作者不收集身份证、出生日期或人脸，不接实名认证API，也无法保证对方声明真实。
- 使用者可以自行保管、展示或转发下载文件，也可能将工具部署到自己控制的服务器。这些行为和服务器不在作者的实际控制范围内，不能默认作者参与或可以干预。

前两项中的代码和网络行为已有源码检查及Chromium/WebKit连续11轮回归证据。没有验证的部署环境仍标明未验证，不把未知情况反向写成作者存在收集或传播行为。

## 分别判断各主体的行为

| 对象或行为 | 本次结论 |
| --- | --- |
| 使用者在本机输入、存储、压缩和导出 | 属于软件在本机执行的操作。不能只因作者编写了这些功能，就认定作者在收集或处理这些个人信息。 |
| 作者接收、查看、出售或提供填写内容 | 当前事实和实现均不支持存在这些行为，不能将其列为已发现的违法或整改事项。 |
| 使用者自行展示、转发或上传PDF | 当前工具不提供公开发布或分享接口。使用者的独立后续行为不能自动归责于作者，也不要求作者控制对方设备或删除对方副本。 |
| 他人部署的服务器、代理或日志 | 按实际部署和控制主体判断。本报告不要求作者管理自己没有控制权的服务器；作者自行运营某个入口时，才另行审查该入口实际由其决定的配置和行为。 |
| 18岁声明 | 已实现尽力确认。无法证明真实年龄是技术能力边界，不能单凭这一点认定作者违法。本次审查没有找到并论证一项适用于本工具、要求接入实名认证API的具体义务，因此不把实名认证、收集证件或远程核验列为整改要求。 |
| 作者随工具提供的固定题目、分类和提示 | 这些属于工具自身内容，应与使用者的私密答案、图片及PDF分开讨论。审查自带内容不代表要求作者查看用户资料或控制用户展示。 |

## 《个人信息保护法》的适用边界

第4条列举个人信息处理活动，第73条涉及个人信息处理者的认定。把浏览器操作称为技术上的“处理”，并不能直接回答法律上的处理者是谁。需要结合实际由谁决定处理目的和方式、谁实施相关行为判断，不能以“写了表单和导出代码”代替这一分析。

当前报告没有建立作者作为使用者填写内容的个人信息处理者的充分事实依据。因此，撤回此前将敏感信息单独同意、全部必填的最小必要性、个人信息保护影响评估及删除第三方副本直接列为作者整改任务的写法。这些规定有各自的适用前提，不能先假定作者是处理者再套用。

作者看不到数据、不接收数据，是本次判断的重要事实；也不把其中某一项单独写成适用于所有产品的普遍免责规则。第72条关于自然人个人或家庭事务的规定应针对具体行为分析，既不能默认工具作者适用，也不能默认使用者所有后续行为均适用。

保留准确的本机保存、文件保管和清理说明，是对工具功能的说明。它不意味着作者持有资料，也不意味着作者必须遥控用户设备、相册、下载目录或第三方服务器。

## 《刑法》及公开自带内容的审查范围

《刑法》第253条之一涉及侵犯公民个人信息的行为和法定情节。当前没有作者非法取得、出售或提供填写资料的事实依据，不能以“别人可能滥用工具”替代具体行为与构成要件分析。

此前报告提及第363、364、367条，应当明确对象是作者实际提供或发布的自带内容，而不是使用者自己输入或自行展示的图片和PDF。第363条中的牟利目的、第364条相关行为与情节、第367条关于内容的界定，均须分别论证。性、裸体、暴力相关词语的出现，不足以直接认定整份题库属于法定淫秽内容或认定作者构成犯罪。治安责任同样需要具体内容、行为和适用条件，不能自动从题目关键词推导。

固定题库、分类和提示已存在于静态资源中，本次没有完成对其整体语境及法律性质的专业内容判断。因此，这一项应记为“自带内容的法律性质尚未作出结论”，不再笼统写成已经发现重大违法问题或已经证明不能上线。只有提出具体条目、完整语境、适用依据和判断理由，才能形成有针对性的修改建议。

18岁声明应如实描述为使用者自我确认。本次不将其视为真实年龄证明，也不把不能查明真实年龄本身列为违法事实或要求作者新增身份信息处理。某项具体内容或服务如另有法定限制，需要先证明该限制适用，不能靠泛化风险提示增加义务。

## 修订结论

现有技术证据支持：工具没有向作者上传填写资料，也没有向公众展示使用者填写结果的功能。没有依据要求作者为使用者独立分享、对方服务器或无法验证真实年龄这些事实承担当然责任。

后续审查限于作者实际实施、决定或控制的行为，以及其自带内容。需要补充判断的项目明确标为未形成结论，不把未知当作违法；同时，本报告也没有对所有可能的使用方式出具零风险结论。此次仅更正文档，未新增身份核验、数据收集或分享功能，既有11轮技术结果不受影响。
