# WebTable 本机填写系统设计规范

本规范应用于 Vue 3 + shadcn-vue 的长表单。使用系统中文字体、Lucide 图标，不加载外部字体或营销模块。三套风格共用组件、信息结构和业务逻辑。

## 主题令牌

| 风格 | data-theme | 主色（浅色/暗色） | 圆角 | 表面 |
|---|---|---|---|---|
| 极简 | minimal | #254c3f / #9bd7be | 10px | 暖白、细边框、少量阴影 |
| 科技 | tech | #245ac3 / #94baff | 6px | 冷灰、蓝色强调、清晰分区 |
| 扁平 | flat | #8c3a20 / #ffb398 | 16px | 温暖背景、纯色分区、无投影 |

统一使用 background、foreground、card、muted、muted-foreground、primary、primary-foreground、border、input、ring、destructive、success 等语义令牌。暗黑模式独立于风格，使用 html.dark；局部组件禁止写入风格专属颜色。使用者选择风格和明暗模式，偏好保存在本浏览器。

## 布局与排版

桌面为步骤侧栏加可伸缩内容区，小屏改为顶部步骤导航。填写端最大宽度 1120px，三步导航、保存状态和当前步骤清楚可见；自评按分组折叠，保留未填统计。基础信息、自评备注和级别全部必填。照片四类四槽，在本机选择、处理并保存，说明原件、压缩与重复规则。

系统字体 16px 正文，14px 辅助信息，12px 仅用于少量编号；标题 24–32px。间距 4/8/12/16/24/32px。长文本 overflow-wrap:anywhere。375px 小屏无页面横向溢出，操作目标至少 44px。表格小屏转卡片或在明确容器内滚动。

## 反馈与可访问性

输入必须有可见 label；加载、失败、空状态分别展示。自动保存状态显示“待保存/保存中/已保存/离线待重试/版本冲突”；冲突保留本地编辑，不自动覆盖。清除草稿和确认已保存等操作提供明确确认。表格状态同时使用文字，不能只靠颜色。键盘焦点可见，弹窗可关闭且标题明确，主内容提供跳转入口。

仅使用 150ms 颜色/透明度反馈，遵守 prefers-reduced-motion。不使用装饰性渐入、无限动画或使布局位移的悬停。本机图片处理和PDF生成显示进度，支持失败重试。正文前景对背景至少 4.5:1。所有成功提示通过 aria-live 输出，错误使用 role=alert。
