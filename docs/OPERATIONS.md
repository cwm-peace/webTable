# 维护说明

部署内容只有静态文件。监控可用率、静态资源错误、带宽和缓存命中，不记录用户填写内容。升级采用完整构建目录原子切换，保留旧版本一段时间供已打开页面加载懒加载资源；不要只替换index.html后立即删除旧hash文件。

当前字库URL包含内容hash，采用长期immutable缓存；HTML通过缓存重新验证获取新构建。中文字体有SIL OFL许可与来源记录，随构建发布。网页不注册Service Worker，避免旧缓存持续运行不同版本。IndexedDB结构变更需明确升级、回归恢复及阻塞行为，不直接清空已有草稿。

生产不备份填写内容；填写者本机草稿及下载文件由其管理。旧后端数据库和项目外恢复目录未删除，属于重构前资产，不能据纯前端上线推断旧资料已经清除。由数据所有者按其实际义务另行管理。

复测命令和结果见README与VERIFICATION。更新依赖后重跑单测、三引擎和最终候选回归，检查npm audit；零条已知漏洞不意味着不存在未知缺陷。浏览器系统升级后补做相册、文件保存、附件提取和后台恢复的真机验收。

服务器维护需同时核查实际运行二进制与发行版补丁；自定义静态链接的Nginx/TLS库不一定能通过系统包更新获得修复。系统更新和重启前验证SSH备用登录与Nginx开机启动、ACME续期和回滚路径，避免只验证网页构建。

当前访问日志已关闭。分析旧日志只能说明其覆盖窗口，不能计算此后的实时流量或把不同IP当作人数。若启用后续性能统计，采用不含IP、查询串、UA、Referer、Cookie或填写内容的固定资源类别与字节/耗时汇总，并限定留存；不要直接恢复combined格式。2026-10-17审计的脱敏证据和执行策略仅存于本机忽略目录`artifacts/server-audit-20261017/`。

2026-10-17加固补充：根据产品限制继续保留root密码认证，但认证方式限制不妨碍安装OpenSSH补丁。实际站点已采用官方验签Nginx RPM、发行版动态TLS库、gzip_static和systemd管理；不要再编辑旧自定义目录配置来修改当前服务。更换或回退二进制须同时核对systemd和ACME重载命令。内核包安装完成不等于运行内核更新，必须分别记录安装版本、当前`uname -r`和是否实际重启验收。
