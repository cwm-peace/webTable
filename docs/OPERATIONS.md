# 维护说明

部署内容只有静态文件。监控可用率、静态资源错误、带宽和缓存命中，不记录用户填写内容。升级采用完整构建目录原子切换，保留旧版本一段时间供已打开页面加载懒加载资源；不要只替换index.html后立即删除旧hash文件。

字体路径没有hash，通过ETag重新验证。中文字体有SIL OFL许可与来源记录，随构建发布。网页不注册Service Worker，避免旧缓存持续运行不同版本。IndexedDB结构变更需明确升级、回归恢复及阻塞行为，不直接清空已有草稿。

生产不备份填写内容；填写者本机草稿及下载文件由其管理。旧后端数据库和项目外恢复目录未删除，属于重构前资产，不能据纯前端上线推断旧资料已经清除。由数据所有者按其实际义务另行管理。

复测命令和结果见README与VERIFICATION。更新依赖后重跑单测、三引擎和最终候选回归，检查npm audit；零条已知漏洞不意味着不存在未知缺陷。浏览器系统升级后补做相册、文件保存、附件提取和后台恢复的真机验收。
