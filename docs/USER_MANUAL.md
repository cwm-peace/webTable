# 用户与管理员手册

本文档说明填写者和管理员的日常使用流程。所有页面都面向 PC、手机浏览器、安卓、iOS 和鸿蒙浏览器做响应式适配。

## 1. 角色说明

| 角色 | 入口 | 权限 |
|---|---|---|
| 填写者 | `/` | 创建草稿、填写三步信息、上传照片、最终提交 |
| 管理员 | `/admin` | 登录、查看已完成提交、查看详情、导出单条 PDF、导出全部 Excel |

管理员只能看到已经最终提交的数据，无法通过管理端查看仍在填写中的草稿。

## 2. 填写者流程

### 2.1 打开填写页面

访问系统首页 `/`。首次打开时系统会创建一份草稿，并在浏览器本地保存会话标识。刷新页面或短时间内重新打开时，会优先恢复未完成草稿。

### 2.2 填写基础信息

在第 1 步填写基础信息。页面会按手机和 PC 屏幕自动调整布局：手机端为单列，PC 端为多列。

### 2.3 上传照片

第 2 步按页面中的类别上传照片。规则：

- 每个类别最多 4 张。
- 单张照片最大 50MB。
- 仅支持 JPG、PNG、GIF、WebP、BMP。
- 后端会校验真实图片文件头，伪造 MIME 的文件会被拒绝。
- 删除照片后再次上传会自动补回空槽位。

### 2.4 填写自评

第 3 步按左右分组选择级别和备注。服务端限制左侧最多 65 行、右侧最多 60 行，避免异常请求写入超大数据。

### 2.5 保存与最终提交

切换步骤时系统会分步保存当前数据。最终点击保存提交后，会弹出预览确认。确认后：

- 提交状态变为已完成。
- 浏览器本地会话标识会被清理。
- 后端会拒绝旧会话继续修改该提交。
- 数据进入管理员列表。

## 3. 管理员流程

### 3.1 登录

访问 `/admin`，输入管理员密码。管理员密码由部署环境中的 `WEBTABLE_ADMIN_PASSWORD` 配置。

安全规则：

- 密码错误会返回错误提示。
- 同一客户端多次失败会被临时锁定。
- 登录成功后管理员 token 存入浏览器本地存储和 Redis。
- 退出登录会吊销 Redis 中的 token。

### 3.2 查看提交列表

登录后进入 `/admin/dashboard`。列表只显示已完成提交，支持分页：

- 默认每页 20 条。
- 服务端限制单页最多 100 条。
- 桌面端使用表格布局。
- 手机端使用卡片布局。

### 3.3 查看详情

点击列表中的详情进入 `/admin/detail/:id`。详情页包含：

- 提交摘要。
- 基础信息。
- 照片元信息和预览。
- 左右自评数据。

详情接口不会返回填写端 `sessionToken`。

### 3.4 导出 PDF

在详情页导出单条 PDF。PDF 包含基础信息、照片和自评表格。

注意：

- PDF 只允许导出已完成提交。
- 单个提交照片总量默认超过 100MB 时会拒绝导出 PDF，防止大图组合造成服务端资源压力；需要压缩或减少照片后重新提交。
- emoji 等增补平面字符会在写入 PDF 前过滤，避免字体异常。
- API 响应会设置禁缓存头，减少敏感导出文件被浏览器缓存的风险。

### 3.5 导出 Excel

在管理员列表页导出全部已完成提交。Excel 导出规则：

- 后端按每 500 条提交分批查询，避免一次性加载全部关联数据。
- 空数据也会导出带表头的工作簿。
- 用户输入中以 `=`、`+`、`-`、`@` 开头的文本会被转义，避免公式注入。

### 3.6 退出登录

点击退出登录后，前端会请求 `/api/admin/logout`，后端会立即删除 Redis 中的管理员 token。token 过期或被吊销时，前端会自动回到登录页。

## 4. 常见问题

| 问题 | 处理方式 |
|---|---|
| 页面刷新后草稿还在 | 这是预期行为；最终提交后会清理本地会话 |
| 提交完成后无法继续修改 | 已完成提交会锁定，防止旧 token 改写历史数据 |
| 管理端看不到某条草稿 | 管理端只显示最终提交的数据 |
| 上传照片失败 | 检查文件格式、文件大小、网络连接和后端上传限制 |
| PDF 导出失败并提示照片总量超过上限 | 该提交照片总字节数超过部署配置，压缩或减少照片后重新提交 |
| 管理端突然回到登录页 | 管理员 token 过期、被吊销或 Redis 数据失效，需要重新登录 |
| 手机访问失败 | 检查设备是否能访问前端地址，以及前端来源是否配置在 CORS 白名单中 |

## 5. 隐私与安全提醒

- 不要把管理员密码写入代码仓库或前端文件。
- 不要共享管理员账号给不可信人员。
- 下载的 PDF/Excel 可能包含敏感信息，应按内部安全要求保存和删除。
- 部署生产环境时建议使用 HTTPS，并避免 Redis/MySQL 暴露到公网。
