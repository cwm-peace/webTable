# 使用说明

进入页面后确认已满18周岁。该提示按草稿保存，刷新同一份草稿不重复；清除后开始新表单会再次确认。

按基础资料、图片、自评三个步骤填写。所有文字字段都要填，没有对应内容可填“无”或“不适用”。125项级别必须选择A至E，四类图片各四张。前进或导出发现缺项时，页面列出可点击的错误并定位相应输入。

文字会在停止输入约1秒后保存在本浏览器。显示保存失败时请重试，不要把它当作已保存。换浏览器、换设备或清理站点数据后无法恢复；隐私模式和系统空间回收也可能清除草稿。另一标签页编辑时本页只读。刷新后若上一页租约尚未释放，可稍候约9秒；发生编辑冲突时需明确重新读取。

图片选择在本机处理，没有上传进度。支持JPEG、PNG、WebP以及浏览器能解码的GIF、BMP、AVIF、TIFF、SVG、HEIC／HEIF；容量与尺寸规则见第2步提示。照片超过2500万像素或最长边8192时自动缩小，不需要先手动处理；动图只取第一帧。iPhone的HEIC照片在Safari可以处理，在Chrome等没有内置HEIC解码器的浏览器会提示先转换为JPEG。原图可能包含拍摄位置，生成的PDF也包含图片附件，请自行保管。只比较文件字节重复，不识别相似画面。

最后点击“检查并生成PDF”，生成期间可取消，失败后草稿仍保留。PDF按报告式版面排版：基础资料分组两列显示，125项自评排成表格，16张照片各占一页并带容量与像素说明，页脚有页码。完成后点击“下载PDF”。iPhone/iPad等设备如果下载不明显，可点击“打开PDF”，通过浏览器分享菜单存储到“文件”。部分阅读器只能看正文，提取嵌入原图需支持PDF附件的阅读器。

中文字体没有 emoji 等字符的字形时，PDF 会用 □ 代替这些字符，并在页面与 PDF 正文中列出被替代的码位；草稿里的原文不会被改动。确认PDF已保存且可打开，再勾选保存确认并清除。下载按钮、浏览器下载事件或关闭预览不代表文件已经妥善保存，所以不会自动清理。清理仅删除本应用草稿、图片引用与生成文件地址，不删除相册原件、下载PDF、截图或系统备份。外观偏好会保留。

存储受限时可明确选择临时填写。临时模式刷新或关闭页面会丢失内容，页面持续显示提示。若清理时仍无法访问磁盘存储，只会报告本页内存已清理，并提示通过浏览器设置清除此网站数据。
